Alkenes have an electron-rich C=C double bond. Br₂ acts as an electrophile, attacking the π bond. This is electrophilic addition — Br₂ adds across the double bond, decolourising the water.

The C=C double bond in alkenes is electron-rich, making it a target for electrophiles like Br₂. Think of Br₂ as being "attracted" to the electrons in the double bond. 🧪
Why does bromine water decolourise specifically?
Great question! The brown colour comes from Br₂ molecules. When they react with the alkene, all the Br₂ gets consumed forming a colourless dibromoalkane — no Br₂ left = no colour! This is the classic unsaturation test.
What if I use HBr instead?
Same type of reaction — electrophilic addition! H⁺ adds first (Markovnikov's rule), then Br⁻ follows. JAMB loves asking about Markovnikov. Want me to explain it? 📝
